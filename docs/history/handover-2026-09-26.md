## How we worked this sprint

The owner allowed a faster path while the budget was cut. Keep it unless the
owner says otherwise:

- Work straight on `main`. Rebase onto `origin/main` and run
  `DATABASE_URL=… ./scripts/gate.sh` and `./scripts/gate-features.sh` once
  on the rebased tip. Push with `git push origin HEAD:main`, never with force.
  Gate again only if the rebase touched your files.
- One cargo gate at a time on this machine. The sessions use
  `/Users/viktor/.baylee-locks/with-cargo-lock.sh`.
- Stage by file list, never with `git add -A`.
- Inject a fault into a test only where it guards something legal or
  safety-related.
- Send the owner one screenshot per deliverable. Live checks run on a copy of
  the config (`XDG_CONFIG_HOME` in a scratch directory), never on
  `~/.config/baylee`.
- The owner's Pixel is off limits. Test mobile on the Android emulator and the
  iOS simulator only.
