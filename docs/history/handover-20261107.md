## BayleeAI: what is measured

| Comparison | Result |
| --- | --- |
| FP16 against FP32, 2,048 deals, tactics | 1,004 against 1,003 wins, 2.2 times faster, 55 % of the memory |
| v6 against last v5 / s1r, both raw | 64.5 % / 54.1 % |
| Same, both with tactics | 49.8 % / 50.6 % |
| v6 with all rule groups against v5 with tactics | 60.2 % / 60.7 % |
| With tactics against DeepSeek, Flash, Haiku Max (Phase D) | 27.4 %, 16.8 %, 15.3 % |
| 18-group rule bundle against language models | +3.8 points [-2.7, +10.1] |

The v5 table has 512 deals per cell. Last v5 is handicapped by its old catalog, so read `s1r`. The net
has not measurably passed v5; the gain so far is the rule layer, and v5 was not given those rules.
Strength has to come from new learning signals, not more of the same.

The new value head, on a frozen trunk with the policy untouched, reads the change between positions
better than the old head (.733 against .671) and the board baseline (.715), and on language-model
games .742 against .695. It missed the goal fixed beforehand by two narrow bands, and it is
overconfident: it says .96 and wins .77. A learned scale (`gain`) fixes the slope and misses the mean.
