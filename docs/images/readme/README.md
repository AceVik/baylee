# README recordings

The loops here are recordings of the running client. Those at the table and
in the deck builder (`table`, `combat`, `payment`, `replay`, `deck-builder`,
`keyword-borders`) show card images © Wizards of the Coast, provided by
[Scryfall](https://scryfall.com). The card images are not covered by this
repository's licence (AGPL-3.0); they are shown as unofficial Fan Content
under Wizards of the Coast's
[Fan Content Policy](https://company.wizards.com/en/legal/fancontentpolicy),
as the game draws them and only scaled, and no Universes Beyond card appears
in them. The front door, the lobby, the room and the update card show no
card.
